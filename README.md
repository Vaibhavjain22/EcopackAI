# 🌱 EcoPackAI -- Sustainable Packaging Material Recommendation System

## 📌 Overview

EcoPackAI is an AI-powered system designed to recommend the most
suitable and eco-friendly packaging materials for different product
types. The system considers factors such as CO₂ impact, cost efficiency,
and material suitability to provide optimal recommendations.

This project integrates Machine Learning, Backend APIs, Database
Management, and Frontend UI into a complete end-to-end system.

------------------------------------------------------------------------

## 🚀 Features

-   AI-Based Material Recommendation\
-   Environmental Impact Analysis\
-   Cost Efficiency Prediction\
-   Smart Ranking System\
-   Flask REST API Backend\
-   PostgreSQL Integration\
-   Interactive Frontend UI

------------------------------------------------------------------------

## 🏗️ System Architecture

User → Flask API → ML Model → Database

------------------------------------------------------------------------

## 🛠️ Tech Stack

-   Backend: Flask (Python)\
-   Frontend: HTML, CSS, Bootstrap, JavaScript\
-   Database: PostgreSQL\
-   Machine Learning: Scikit-learn\
-   Data Processing: Pandas, NumPy

## ⚙️ Setup Instructions

1.  Clone repo\
2.  Install dependencies: pip install -r requirements.txt\
3.  Setup PostgreSQL database\
4.  Run: python app.py\
5.  Open: http://127.0.0.1:5000
